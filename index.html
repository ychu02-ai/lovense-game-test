Scanner says "not supported" — how to enable it
Live scanning is still an experimental Chrome API. On Android open chrome://flags/#enable-experimental-web-platform-features, set it to Enabled, relaunch Chrome, and reload this page. If you'd rather not, skip to section 2 and use the Manufacturer-data filter — it needs no flag and will show your toy even if it has been renamed.

Toy still not showing up — read this
  1. The toy may have been renamed. A custom name set in the Lovense app replaces the advertised LVS-… name, which is why a name-prefix search finds nothing. The manufacturer-data filter above ignores the name entirely. To restore the default, clear the name field in the Lovense app's toy settings.
  2. Force-quit every Lovense app on every nearby phone/PC (Remote, Connect, Lovense Bridge). A held connection stops the toy advertising, so nothing — not Chrome, not nRF Connect — can see it.
  3. Do not pair it in Android Bluetooth settings. These toys are BLE-only; a system pairing entry can block app-level connections. If one exists, "Forget" it.
  4. Wake it properly. Charge it above ~30% first, then press the power button until the LED blinks. Solid or dark = asleep or already connected. A toy that has been idle for a while stops advertising until the button is pressed again.
  5. If even the Lovense app can't find it, that is a toy-side problem, not a browser one — charge it fully on the magnetic cable (check the pins are clean and seated) and try again.
  6. Android: Bluetooth and Location on; Chrome needs "Nearby devices" (Android 12+) or "Location" (Android 11−) permission.
  7. Page must be on https://. file:// will not work.
