Toy won't show up / won't connect — checklist
  1. Force-quit the Lovense app (and Lovense Remote / Connect on any nearby phone or PC). While the app holds the toy, it stops advertising and Chrome cannot see it.
  2. Do NOT pair it in Android Bluetooth settings. Lovense toys are BLE-only; a system pairing entry can block Chrome. If one exists, "Forget" it.
  3. Wake the toy. Short-press the button once — the LED should be blinking (advertising). Solid / off = asleep or already connected to something.
  4. Android: Bluetooth and Location services must be ON, and Chrome needs the "Nearby devices" permission (Android 12+) or "Location" (Android 11−).
  5. The page must be served over https:// (GitHub Pages is fine). file:// will not work.
  6. Toy must be charged above ~20%; low battery kills BLE range first.
  7. If the picker is empty, tick "Show all BLE devices" — Lovense names vary (LVS-…, LOVE-…, or the bare model name).
  8. If it connects but "no usable service" appears, install nRF Connect, read the toy's service UUID, and paste it into "Extra service UUID" above.
